# AndreOS

> This is my resume/portfolio website. I used 98.css to mimic old school windows 95 operating system and each react component is a separate app. I plan on adding more components. I will probably change the name of it as well. AndreOS is fairly boring. The goal is for this is to showcase what I know and what I can do and if they wish to contact me they can do so with ease. The Windows can be resized, minimized, expanded. There is also a taskbar with a start menu. The display properties can be customized as well.
